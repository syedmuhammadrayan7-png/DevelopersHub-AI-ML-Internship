# Task 1: Exploring and Visualizing the Iris Dataset

## Objective
The objective of this task is to load, inspect, analyze, and visualize the Iris dataset using Python libraries such as pandas, matplotlib, and seaborn.

## Dataset
The Iris dataset was used for this task. It contains flower measurements such as sepal length, sepal width, petal length, petal width, and species.

## Work Performed
- Loaded the Iris dataset
- Displayed dataset shape
- Displayed column names
- Displayed first few rows using head()
- Checked dataset information using info()
- Generated summary statistics using describe()
- Created scatter plots to show relationships between features
- Created histograms to show feature distributions
- Created box plots to identify possible outliers

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn

## Key Insights
- The dataset contains three Iris flower species.
- Petal length and petal width are useful features for separating species.
- Scatter plots helped visualize relationships between features.
- Histograms showed the distribution of numerical columns.
- Box plots helped identify spread and possible outliers.

## Conclusion
This task helped in understanding basic data exploration and visualization techniques using pandas, matplotlib, and seaborn.
